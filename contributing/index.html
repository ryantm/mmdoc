Contributing

For easy development, nix with flakes support is recommended.

Test

The flake uses drvc to build the native Meson project. It reads the source file set, system libraries, and build tools from drvlang.json. Enable nix-command, flakes, ca-derivations, dynamic-derivations, and recursive-nix on the client and daemon. The builder also needs the recursive-nix system feature.

Compile mmdoc and run its tests:

$ nix build
$ nix flake check

Run the same tests through the drvc CLI:

$ nix run github:drvlang/drvc -- test -C .

To use a local Meson development build:

$ mkdir build && cd build
$ meson ..
$ ninja test

Format

$ nix fmt

Documentation

Build the mmdoc docs to ./result with:

$ nix develop -c doc-build

Continuosly build the mmdoc docs and serve them on port 8000 with:

$ nix develop -c doc-watch

Making a new release

  1. run ./contrib/release {major.minor.patch}. For example, ./contrib/release 0.16.0.
  2. edit commit message
  3. push commit and tags to GitHub
